# Windows IDEA 对齐性能记录

记录日期：2026-09-30。构建使用 Windows 产品对应的 Release 优化：opt-level=3、lto=thin、codegen-units=1。测量通过 Core C ABI，包括响应 JSON 解析；不包括 React 绘制、WebView IPC 和用户输入到可见结果的时延。

## 项目与搜索范围

同机实际 Java 项目，原候选约 2 万文件；项目忽略规则启用后约 3300 文件，可搜索内容约 16.7 MB。Windows 项目查找默认排除 Git 忽略文件；包含开关可恢复原范围。项目外的父级和全局 Git 规则不参与本次项目范围。

原单次基线：常见词首批 141 条 152ms，稀有词 24 条 4702ms，无结果 4686ms。新范围稀有词命中 11 条；命中数量变化来自排除工具及临时目录，不能当作相同范围的纯算法加速。
